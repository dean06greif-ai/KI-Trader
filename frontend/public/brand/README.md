# Logo-Varianten (MarketMaker)

- `logo-monogram.svg` – MM-Monogramm mit Aufwärtspfeil (aktiv)
- `logo-candles.svg`  – Candle-Optik (grüne/rote Kerzen bilden „MM“)
- `logo-bidask.svg`   – Bid/Ask: grünes + weißes M versetzt

Aktive Variante = `public/favicon.svg` (+ PNG/ICO). Wechsel: `python3 scripts/make_icons.py <variante>`
(benötigt `pip install cairosvg pillow`), erzeugt favicon.svg/.ico, apple-touch-icon, icon-192/512, maskable.
